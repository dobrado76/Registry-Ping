Registry Ping

Lightweight community sample for the LSM Studio app registry. Use it to verify GitHub install, launcher branding, View Manifest, and embedding after install into apps_installed/registry_ping/.

Main screen: project file tree plus shared CodeEditorPanel. Sample files live in data/. Telemetry and developer console at the bottom confirm shared lsm_core widgets load correctly.

Maintainer docs: repository README.md and catalog_submission.json for MMG catalog listing.
